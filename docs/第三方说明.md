# 第三方组件与素材说明

## Shizuku

项目使用 `dev.rikka.shizuku:api:13.1.5` 和 `dev.rikka.shizuku:provider:13.1.5`，源自 [Shizuku API](https://github.com/RikkaApps/Shizuku-API)，按 MIT 许可证使用。

完整版权与许可声明保存在 [SHIZUKU-LICENSE.txt](../app/src/main/assets/SHIZUKU-LICENSE.txt)，同时随 APK 打包。

## 卡面素材

离线卡面包从以下公开来源整理：

- [Cardentify 网站](https://cards.no2.ac/) 与 [Cardentify 投稿 Issue](https://github.com/no2ac/Cardentify/issues)。
- 小米钱包公开公交产品目录返回的图片资源。
- MiPayCard 社区目录与原 APK 内置图片。

图片的权利归各自权利人，卡面包保留原图、来源页和原始图片链接。社区来源名称沿用原记录，不代表逐张认证为官方素材。SVG 附带用于 Android 裁切的 PNG，原始 SVG 另外保留；ZIP / PDF 附件原件亦保留在离线包中。

源码与卡面包分开发行。发布内容不包含钱包 APK、反编译的第三方源码、手机私有数据库、账户数据或签名密钥。
